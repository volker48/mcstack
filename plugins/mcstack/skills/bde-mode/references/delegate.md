# Delegate brief

You are a delegate of a `/bde-mode` run. The chat that runs `/bde-mode` owns the playbook, the todo list, and every subagent spawn.

Before any work, read the bde-mode skill's `SKILL.md` in full, including its inline Principles index, at the absolute path your parent gave you. This file sits in that skill's `references/` folder, so the `SKILL.md` is one directory up. Your skill catalog may hide bde-mode, so a missing catalog entry does not mean mcstack is absent. If the file does not exist, stop and tell your parent.

Read a leaf `principle-*` skill whenever you apply that principle. The principle skills sit beside bde-mode's directory, at `../principle-<name>/SKILL.md` from it.
